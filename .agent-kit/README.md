# agent-kit, vendored

A copy of `plugin/` from george-sprangas/agent-kit at `624a0e6`.

Do not edit here: changes go to the kit, and this copy is refreshed with
`python3 scripts/vendor_plugin.py <this repo>` from a kit checkout, on a
branch, by pull request. The cloud environment's setup script installs the
plugin from this directory, because a cloud sandbox receives files only
through the repositories it checks out.
